# 《叙事权》（暂名）——《自由度》子项目

《自由度》丛书的姊妹分析项目：freedom 用"约束分析"看自由，本书用同一双眼睛看**命运叙事**——命是怎么被讲出来的、被谁讲出来的、怎么拿回笔。

> freedom 拆锁，本书拆剧本。

**体量小于 freedom，广度与深度不降**：reference/ 素材全覆盖，学科覆盖按 freedom 标准（跨学科同构：意识形态理论、社会心理学、临床心理学、社会学、政治哲学、语言学、神经科学、文学、影像与艺术）。

## 构建与预览

构建使用独立工具 **quire**（https://github.com/wurui1994/quire，CLI + SDK 通用）。卷的发现按目录约定，与本仓库结构天然对齐，无需登记；例外是根下 `bibliography.md`，按 freedom 惯例以 `quire.toml` `[[volume]]` 登记为书末附录卷（导读册、正文之后）。

```sh
pip install -e "git+https://github.com/wurui1994/quire.git#egg=quire"   # 一次性安装

quire build                               # 全部卷 → dist/（HTML + EPUB + PDF + index.html）
quire build vol0-谁在讲                   # 只构建导读册；--html / --epub / --pdf 可三选一
quire build --all-one                     # 全卷合本 all.html / all.epub / all.pdf
quire serve                               # 预览 http://localhost:8000（改动即生效）
quire list --words                        # 卷 / 章节 / 字数清单
quire new vol0-谁在讲/chapters/新章 标题    # 新建章节（自动编号 ch12- 起）
```

- **卷的发现**：`book/vol0-谁在讲/`（目录.md + chapters/）与 `book/chapters/`（正文，副标题「正文」）各成一卷；`vol0-` 前缀即阅读顺序，**导读册严格在前**。散置的 `正文目录.md` 是工作目录稿，按约定不进构建；根下 `bibliography.md` 经 `[[volume]]` 登记为书末「附录　参考文献库」。书名、作者见 `quire.toml`。
- **字体**：默认用系统字体库；如需离线 / 可复现构建，在 `quire.toml` 配 `[fonts]` 目录并 `quire build --cache-font` 缓存字体（做法参照 freedom/scripts/assets/fonts）。
- **封面**：默认排版式版式；如需 freedom 式「约束场」封面，可写封面插件并配 `[cover] plugin`（参照 freedom/scripts/cover.py）。

## 关键约定

- **文体**：继承 `freedom/series/style.md` v2.0。骨头要硬，皮肤要暖，道理不说教。
- **分工**：卷三《心智》讲"你给自己讲的故事"的机制；本书讲"叙事权的社会战场"。独立可读。
- **诚实底线**：不写成成功学（防鸡汤），不滑向相对主义（防虚无）。叙事是现实主义，不是许愿。
- **人称纪律**（作者裁定，全书已终检）：叙述层无"我"——虚构场景一律第三人称并注明虚构，真实案例优先。
- **素材纪律**：reference 三份对话逐条入架（见 plan.md 覆盖对照表）；话术标本已随章内嵌 24 条，总目见 `book/正文目录.md`。
